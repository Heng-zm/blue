# MGS v0.2.1

File size limit removed, extended voice recordings, and radio stability fixes.

## Changes in this release

- **File size limit removed**: Removed the 5 MB ceiling on file transfers. File transfers now utilize the full capacity of the 16-bit binary chunking protocol (up to 256 MiB / 65,535 chunks).
- **Extended voice notes**: Voice notes can now record for up to 5 minutes (300 seconds).
- **Radio startup fix for iOS/macOS**: Fixed Darwin `Unsupported operation: connectionStateChanged` during BLE startup.
- **Concurrent transfers**: Increased concurrent incoming blob buffer capacity from 8 to 32.
