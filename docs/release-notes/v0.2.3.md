# MGS v0.2.3

Brand-new app icon, same Wi-Fi link, and USB tethering mesh links.

## Changes in this release

- **Custom app icon**: Designed and rendered a sleek new geometric mesh icon in electric lime (`#C9FF6A`) and cyber mint (`#62E6C8`) across Android mipmaps, iOS AppIcon set, and Windows ICO resources.
- **Same Wi-Fi link (Local LAN)**: MGS peers on the same local Wi-Fi router, access point, or ad-hoc mobile hotspot automatically discover each other via UDP beacons and establish high-speed direct TCP mesh links.
- **USB link (Tethering & ADB)**: Full support for USB tethered connections (e.g. Android USB tethering `192.168.42.x`, Windows ICS `192.168.137.x`) and ADB loopback port forwarding (`127.0.0.1:52525`) with automatic background probing.
- **Direct Connect by IP**: New "Direct Connect by IP" sheet in Settings allowing direct point-to-point connections to any local IP address with one tap.
- **Multi-transport mesh routing**: Messages, blob files, photos, and voice notes seamlessly route across both Bluetooth Low Energy and high-speed Wi-Fi / USB links, providing instant wire-speed transfers when peers share a local network.
- **Link badges**: Peer tiles and chat headers now display whether a connected peer is linked over Wi-Fi (`FAST`), USB (`FAST`), or Bluetooth Low Energy mesh.
